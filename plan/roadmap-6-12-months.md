1. 1–3 个月：补齐 C++11/17 基础、并发和工程化，完成线程池与 Windows 工具执行器。
2. 4–6 个月：完成 C++ MCP Server/Client、离线代码审查 Agent、SQLite/Protobuf/gRPC 集成。

4. 10–12 个月：Electron + C++ 本地 Agent 工作台；补齐 IPC、安全隔离、崩溃恢复、可观测性和持续 Benchmark。

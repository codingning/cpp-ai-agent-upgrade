# 面试与简历补充轨

## 每周面试单元

1. C++ 基础：生命周期、拷贝/移动、虚函数、const、模板、STL；
2. 算法：数组/哈希、链表/树、二分/滑窗、图/DP，要求 AC 和复杂度；
3. 系统：进程线程、内存、IO、网络、数据库、Windows/Chromium；
4. 项目追问：背景、个人贡献、难点、失败、修复、验证、取舍和边界。

## Review 清单

- 正确性和边界；
- 生命周期和所有权；
- 并发、取消和关闭；
- 错误处理与可观测性；
- 时间/空间复杂度；
- 测试、Sanitizer、Benchmark；
- CMake/依赖/许可证；
- 是否能脱离 AI 解释核心代码。

## 简历写法

使用“场景 + 个人动作 + 技术机制 + 可验证结果 + 限制”。例如：

> 在 Windows C++ 任务运行时中实现可取消队列和安全关闭，补充并发、异常、重复关闭测试；通过 Sanitizer 和 Benchmark 验证无明显泄漏、线程可回收及吞吐基线。

只有在对应证据真实存在时才允许使用这类表述。

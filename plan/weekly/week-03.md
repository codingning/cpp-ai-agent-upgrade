**② React 组件 + props（30min）** —— 断层 C，寄生补两条 JS 语法
- 在 09-22 那个 `F:\code\vite_react\vite-project` 里动手
- 目标：写一个 `MessageItem` 组件，接收一个 `text` 参数并显示出来；
  在 `App.jsx` 里用三次，传三个不同的字符串
- **教练给结构，你写实现**（红线：不代写）：
  ```
  function MessageItem(props) { ... }        // 第一版：用 props.text
  const MessageItem = ({ text }) => ( ... )  // 第二版：改成箭头函数 + 解构
  ```
  两版都写，第二版就是你「不会」的那两条语法的第一次实战
- > **它是什么**：**组件** = 一个返回 JSX 的函数，函数名首字母必须大写。
  > **props** = 父组件传给子组件的参数，在子组件里是一个对象（只读，不能改）。
  > **箭头函数** `const f = (x) => y` 等价于 `function f(x) { return y; }`。
  > **解构** `({ text })` = 从传进来的对象里直接取出 `text` 这个字段当参数名。
- **先写预测再跑**：我认为 props 改成 `({ text })` 之后，函数体里要写 ___ 而不是 ___

**③ `useState`（45min）** —— 断层 C，寄生补数组解构 + 展开运算符
- 承接周四的 `MessageItem`：现在让消息列表**能增加**
- 目标：一个输入框 + 一个按钮，点按钮把输入框内容追加进消息列表
- **教练给签名，你写实现**：
  ```
  const [messages, setMessages] = useState([])   // 数组解构
  setMessages([...messages, newText])            // 展开运算符
  ```
- **必须先写预测再跑**（这题是今天的核心，答错很正常）：
  > 我认为如果写成 `messages.push(newText)` 而不是 `setMessages([...])`，
  > 界面会 / 不会更新，因为 ___
- > **它是什么**：**useState** = 让组件「记住」一个值，并且值变了就重画界面。
  > 返回一个两元素数组：`[当前值, 改值的函数]`。
  > **数组解构** `const [a, b] = arr` = 把数组第 0、1 个元素分别取名 a、b。
  > **展开运算符** `[...arr, x]` = 造一个**新数组**，内容是 arr 的全部元素再加上 x。
- **这一行是双料锚点**：`const [a, setA] = useState()` 同时教会你
  「useState 怎么用」和「数组解构是什么」。你不会的语法在这里第一次有真实用途。

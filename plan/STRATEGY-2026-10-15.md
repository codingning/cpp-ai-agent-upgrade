## 三、为什么上午 C++ 不动，权重反而上升

旧方向里 C++ 是「底座」，新方向里 C++ 是**主业本身**。
Chromium 内核 / C++ 基础设施岗面试的第一道墙就是现代 C++ + 并发 + 内存模型，
原本排在阶段二「副线」的 C++ 并发（thread / mutex / condition_variable / 线程池），
**现在升为上午主线内容，不再是副线**。

# 训练营项目对标与选择决策

## 决策

半年采用“一主一副”：

- 主项目：PR Agent + 本地工具运行时；
- 副项目：mini-llama.cpp 可验证切片。

AI 数字人和视频会议保留为架构参照与局部实验，不承诺半年内做出完整商业系统。

## 为什么不是四个一起做

四个项目分别涉及实时音视频、深度学习推理、Agent 编排、网络协议和桌面工程。以每天最低 1 小时计算，同时完整交付会把每个项目都压缩成演示样例，无法形成高级工程证据。主副项目策略能让基础、并发、工程化和架构知识在同一条证据链中复用。

## 项目达到“可对标”的标准

不是项目名称相同，而是至少覆盖对应核心难点：

- PR Agent：diff 解析、工具调度、权限、结构化审查、证据引用、人工审批；
- mini-llama.cpp：张量/内存、Tokenizer、前向计算、KV Cache 或采样、Benchmark；
- AI 数字人参照：音频/文本输入、推理任务、流式调度、延迟和资源管理；
- 视频会议参照：媒体采集/编码、信令、并发会话、网络异常和资源释放。

每个项目必须固定依赖版本、保留许可证审计、可本地构建、可测试、可复盘。

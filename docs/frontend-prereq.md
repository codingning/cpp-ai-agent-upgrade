## 6. 结论区（教练填，2026-09-23 14:5x 本人填完后当场写）

### 6.1 真实断层在哪

**断层比教练排课时的假设深两档。**原假设「他会 JS，缺的是 React」——实测错误。

**断层 A（最致命）：JS 语言本体。**
第 1 节七项，本人自评只有「变量/函数/数组/对象基本语法」是「基本能看懂」，
**箭头函数、async/await + Promise、解构赋值、展开运算符四项全标「不会」**。

关键证据是本人自己点破的（09-23 原话）：
> 「用过 箭头函数、解构赋值、async/await/Promise，**但是 Electron 主进程是我从教程里拷贝的。
> 所以并不是全部了解。**」

→ 09-22 教练据「他 Electron 代码里用了这些语法」推断「他会这些语法」，**该推断作废**。
**用过 ≠ 会写**，拷贝来的代码里出现某语法不构成掌握证据。这是本次填表最大的发现。

**断层 B：DOM / HTML 事件。**
`addEventListener`、`getElementById`、HTML 标签结构 + `<script>` 引入，**三项全「不会」**。
但本人 09-21 立场明确：**AI 时代手写 DOM 无意义**。
→ 二者不矛盾：React 的事件系统（`onClick`）确实不需要先学 `addEventListener`。
**不排 DOM 补课**，只在 React 事件课上标一行「原生对应物是什么」。
（此处遵 09-21 本人规则：卡壳时「停下补概念」而非「降级用会的技术」——
但前提是那个概念**在主线路径上**。原生 DOM 不在 React 路径上，故不补。）

**断层 C：React 四件套零基础。**
`组件/props`、`useState`、`useEffect`、`构建时vs运行时` 全「不会」。
本人自己点名前三项为「连它大概想干什么都说不出来」。

**断层 D：构建工具链——只有名词，没有实操。**
npm/package.json/npm run 三项均为「只知道是什么」，**从未自己跑过**。

**已确认不是断层的（有证据，不重复排课）**：

### 6.2 补课顺序

**原则：JS 语法不单独开课，寄生在 React 课里按需补。**
理由——单独学语法他没有反馈回路（写完不知道对不对），
挂在 React 练习上每条语法都立刻有用途、有报错、有输出。
这条与 09-21「不切知识点、只标主线必补」一致：JS 四项**是主线必补**，不是扩展项。

| 序 | 内容 | 寄生的 JS 语法 | 排期 |
|---|---|---|---|
| ① | `npm init` / `package.json` / `npm run` **亲手跑一遍** | 无 | W3D4（09-24）15min |
| ② | 组件 / props | 箭头函数（函数组件就是箭头函数）、解构（`{ text }` 接 props） | W3D4-D5 |
| ③ | `useState` | 数组解构（`const [a, setA] = useState()`）、展开运算符（不可变更新） | W3D5（09-25） |
| ④ | `useEffect` | 箭头函数、闭包 | W4 |
| ⑤ | `async/await` + Promise | 本体 | W4（IPC 异步调用时，有真实用途再学） |

**②③ 是关键设计**：`const [a, setA] = useState()` 这一行同时是
「useState 怎么用」和「数组解构是什么」——**一行代码两个知识点，互为记忆锚点**。
展开运算符同理，`setList([...list, item])` 不学 `...` 就写不出来。

**不排的（写明理由，非切掉）**：
- 原生 DOM / `addEventListener` —— 不在 React 路径上（见 6.1 断层 B）
- TypeScript —— week-01 第 50 行排过，实查 `package.json` 无 TS、全 `.js`，
  **从未落地且一路挂着未标作废**。正式标：**W1-W6 内作废**，
  理由：JS 本体都没过关，加 TS 是负担不是助力。W7 后视情况重排。
  （本人 09-23 回应：「我记不清楚了，应该是你说的跳过吧」→ 责任在教练排课，不在本人。）
- `this` 指向规则 —— 函数组件确实用不到，维持原判「否」

## 六、新内容（60min）· `ThreadSafeCounter`

> 把本周 `thread` + `data race` + `mutex` 三件合成一个能用的东西。
> **这是实现类题，按 10-17 的规矩有两个编译卡点，不许全写完再交。**

在 `F:\code\cpp-practice\week-07\` 新建 `day6_safe_counter.cpp`。

骨架（**只有结构，内容你自己填**）：

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <vector>

class ThreadSafeCounter {
public:
    void Add(long long n);          // 加 n
    long long Get() const;          // 读当前值
    void Reset();                   // 归零
private:
    long long value_ = 0;
    mutable std::mutex mu_;         // mutable 是什么：见下
};
```

**两个你没学过的东西，我直接讲（顺序铁律）**：

1. **`mutable`**：成员变量加了 `mutable`，**在 `const` 成员函数里也能改它**。
   为什么需要：`Get() const` 承诺不改对象，但它要给 `mu_` 上锁 —— 上锁就是改 `mu_` 的状态。
   不加 `mutable` 这里编不过。
2. **`std::vector<std::thread>`**：装一组线程。
   起 N 个线程用 `threads.emplace_back(...)`，等它们全部结束要 `for (auto& t : threads) t.join();`

  跑通并贴输出给我，再往下写
- **第二卡点**：`Reset` 写完再编译一次

- 预测 3（这个最值钱）：`Get() const` 里那把锁 **能不能去掉**？

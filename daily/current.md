> 📖 名词扫盲（非当日主角，各一行，防超纲）：
> - **迭代器（iterator）**：容器里「指向某个元素的位置」的对象，用法像指针（`*it` 取值，`++it` 往后）
> - **失效（invalidate）**：那个位置对象不再指向有效元素，继续用就是 UB
> - **均摊分析（amortized analysis）**：把偶尔一次很贵的操作，平摊到大量便宜操作上算平均代价

### 第 1 段 · 骨架 + 固定 cap + assert

骨架（**这是骨架不是答案，函数体全部留给你**）：

```cpp
template <class T>
class MyVector {
public:
    MyVector();                   // 分配 cap_ = 4 的空间
    ~MyVector();                  // 释放
    void push_back(const T& v);   // 满了就 assert(false)
    size_t size() const;
private:
    T*     data_;
    size_t size_;
    size_t cap_;
};
```

- `assert` 是什么：`<cassert>` 里的宏，条件为假时立刻终止程序并打印哪一行断的。
  它是给**程序员错误**用的，不是给用户输入用的。
- 验收：push 4 个正常，push 第 5 个断在你写的那行。**跑之前先在注释里写死你猜的输出。**

## 二、09:45-11:10 · 85min · 简版 `shared_ptr` 实现（含引用计数）

自己写 `F:/code/cpp-practice/week-06/day6_shared_ptr.cpp`。**写之前先在注释里写四条预测。**

**骨架（只给签名，实现你自己写）**：

```
template <typename T>
class MySharedPtr {
public:
    MySharedPtr() noexcept;
    explicit MySharedPtr(T* p);
    MySharedPtr(const MySharedPtr& o) noexcept;
    MySharedPtr(MySharedPtr&& o) noexcept;
    MySharedPtr& operator=(const MySharedPtr& o) noexcept;
    MySharedPtr& operator=(MySharedPtr&& o) noexcept;
    ~MySharedPtr();

    T& operator*() const;
    T* operator->() const;
    T* get() const noexcept;
    long use_count() const noexcept;

private:
    T* ptr_;
    long* count_;     // 为什么是指针不是 long？这一条你自己想，写进注释
};
```

**要跑出来的四个量**（每个都要有对照）：

1. 拷贝后 `use_count() == 2`；两个指针 `get()` **相等**
2. 一个析构后 `use_count() == 1`，**对象还活着**（在析构函数里打印 `~T` 看时机）
3. 最后一个析构后 `~T` **才**打印一次 —— 这是「谁真正拥有」的证据
4. 移动后源 `get() == nullptr` 且 `use_count()` 不变（移动**不**动计数）

**必须自己踩的坑（预测写出来，跑完对答案）**：
拷贝赋值 `a = b` 时，`a` 原来持有的那份计数**怎么办**？先减还是先加？写错了会怎样？

> ⚠️ 参考资料：`cppreference` 的 `std::shared_ptr` 页面可以查语义，**但代码不许抄**。
> 不许用 `std::shared_ptr` 本身。

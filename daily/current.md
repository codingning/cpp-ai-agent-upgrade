## 一、先验我 10-27 那条推测（15min）

🔴 **我的原话**：「你的 x86 有 `CMPXCHG`，一条指令干完。所以在你这台机上
weak 和 strong 很可能编出一模一样的汇编。」

**我标了「这是推测，我没验」。今天你来验。** 这是 D2 的收尾。

### 做法（一个新文件，不要动 day2）

`week-08/day3_cas_asm.cpp`，内容极短，两个函数各调一种：

```cpp
#include <atomic>
std::atomic<int> g_v{0};

bool use_weak() {
    int expected = 0;
    return g_v.compare_exchange_weak(expected, 1);
}
bool use_strong() {
    int expected = 0;
    return g_v.compare_exchange_strong(expected, 1);
}
int main() { return use_weak() + use_strong(); }
```

> ⚠️ 这段不算你的练习代码（它不实现任何逻辑，只是给编译器看的样本），所以我直接给了。
> 下午那题才是你今天真正要写的。

### 怎么出汇编（这几个你没学过，逐个标它是什么）

```
build-msvc.cmd 不出汇编，要自己加开关。用这条：
cl /std:c++17 /O2 /FAs /c week-08\day3_cas_asm.cpp
```

| 开关 | 它是什么 |
|---|---|
| `/FAs` | 让编译器额外吐一个 `.asm` 文件，里面是汇编 + 穿插你的 C++ 源码行（`s` = source） |
| `/c` | 只编译不链接（我们不需要 exe，只要汇编） |
| `/O2` | 开优化。**必须开** —— 不开优化时函数不会被简化，看不出真实形态 |

产物是 `day3_cas_asm.asm`（跟源码同目录）。然后：

```
findstr /n "cmpxchg use_weak use_strong" day3_cas_asm.asm
```

`findstr` 是 Windows 自带的查找命令，`/n` 显示行号。

> 📌 如果 `cl` 这条命令报「不是内部或外部命令」——那是因为没进 MSVC 环境。
> **这种时候不要绕过去，把报错原文贴给我**，我给你定位（不给代码）。

```
RELAXED : m = 49722 / 50103 / 32868 / 44338 / 85613
```

现在问中间那一档：**release / acquire 落在哪一边？**

**为什么值得测**：看我 10-27 给你那张表 ——
- `release`（用在**写**）：这条写**之前**的所有写，不许重排到它**后面**
- `acquire`（用在**读**）：这条读**之后**的所有读写，不许重排到它**前面**

看上去比 relaxed 强得多。那它能不能挡住 `r1==0 && r2==0`？

🔴 **但你那个实验里，线程 1 的形状是「先写 `g_x`，后读 `g_y`」—— 写在前，读在后。**
上面两条约束，**有没有哪一条管得住「写别跑到读后面」**？

**做法**：在 `day2_store_buffer.cpp` 里加第三个分支 `CASE_REL_ACQ`，
store 用 `std::memory_order_release`、load 用 `std::memory_order_acquire`，**两个线程都要加**。



### 定义原样贴回（省得你翻）

```cpp
bool ok = g_v.compare_exchange_strong(expected, desired);
// g_v == expected  → 把 g_v 改成 desired，返回 true
// g_v != expected  → 不改 g_v，而是把 g_v 当前值【写回 expected 这个变量】，返回 false
```

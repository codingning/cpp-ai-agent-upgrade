### 2.1 R2 `std::ref` 判据题（📌 定级 **M2**）

第一版答 B，**实测反了**（A 改到 `a=11`、B 没改到）。10-20 答对过、七天后答反。
他解释「把题意理解错了」被教练不收（题面两行 `std::ref` 都在，不存在那个读法）。
**但判据题答对了**，本人原话：「**A 被 const 挡住，b（应为 C）被形参挡住**」—— 内容对。
完整三格（教练四格地址实验核过）：

| | 写法 | 结果 |
|---|---|---|
| A | `const int&` + `std::ref` | 绑到原对象（`&x == &a`），**const 挡住写** |
| B | `const int&` + 裸 `a` | **decay-copy 挡住**，引用没穿过去（`&x != &a`） |
| C | `int` + `std::ref` | ref 穿过来了，**形参按值又拷一份**（`&x != &a`） |

**「吃掉引用」有两个不同位置**：B 在传递、C 在接收；A 根本没被吃掉，只是不让改。
📌 **M2 不是 M3**：协议 5.1 要求换实例答对两次且相隔 ≥7 天。下次 **≥11-02** 复测再对一次才升。

### 2.5 🏆 欠账 13 ⑤ 重答（**全程禁用 `O(n)` / `O(n²)` / 摊还三个词**，📌 **M2**）

第一版「翻倍把总拷贝从 O(n²) 降到 O(n)，摊还 O(1)」—— 三个符号全对，但**是结论的名字不是推导**。

### 2.6 🏆 W8 第一课 `atomic` · C 组「两个 atomic 不构成一个 atomic」

**他先写预测「非 0」，再跑**（顺序对）。教练实跑 5 次：

```
run3  g_x=200000  g_y=200000  g_mismatch=42265
run4  g_x=200000  g_y=200000  g_mismatch=127592
run5  g_x=200000  g_y=200000  g_mismatch=132239
```

三行并排看：`g_x`/`g_y` **最终都是 200000 一个没丢**（每个 atomic 自己完全正确），
但中途被抓到 4.2 万~13.2 万次不相等，且**三次数都不一样**（不可复现，与 CASE A 的 `lost` 同指纹）。
→ **atomic 保证单变量每次操作正确，不保证多变量之间的一致性。**
这给他 Q2 第二条判据里那个「**或它是 atomic**」划出了边界。

### Q1 `push_back` 触发扩容时做了哪几件事？

（.h 第 6 行已答，此处重写一遍，看是否还说得出）

>1.申请新内存 2.拷贝/移动旧元素  3.释放旧内存

### Q2 每次扩容只加 1 个位置，push n 个元素总共搬了多少次？

>n*(n-1)/2次

### Q3 每次扩容翻倍，push n 个元素总共搬了多少次？**要写推导过程，不要只写结论**

> ⚠️ 本题 .h 第 29-38 行的推导**是教练给的，不是你推的**。
> 此处必须闭卷重推一遍。推不出来就写「推不出来」，不许回去抄。

>首先, 总共搬了 4+8+12+....2^(k-1) = 2^k - 4  , 2^k 就是最终的 cap_，且 cap_ < 2n ，所以  S = cap_ - 4 < 2n

### Q4 「均摊」到底在摊什么？

>均摊是在摊每次扩容版搬数据的次数/时间，同时因为 需要搬 4+8+...+2^(k-1) = cap_ - 4 < 2n 次 和n是一个量级，所以是O(n),再分摊给每n次操作，就是O(1)

### Q5 `push_back` 之后原迭代器为什么**可能**失效？

>`push_back` 之后,vector可能出现扩容，扩容以后，旧的内存旧失效了，而迭代器指向的是旧内存，所有就可能失效

### Q6 「可能」两个字从哪来？什么情况下不失效？

> （出处：cppreference push_back 页 Invalidation 段，本人已读）

>如果发送扩容，就所有迭代器会失效，如果没有发送扩容，只有end迭代器会失效。

### Q7 模板类的成员函数定义，为什么不能放在 .cpp 里？

>模板是"代码生成器"，编译器要看到模板的完整定义才能实例化。.cpp 文件被独立编译，别的 .cpp 看不到它的内容，所以模板类的成员函数定义放 .cpp 里，用的时候找不到实例化版本，链接器报 unresolved external。

### Q8 `move_if_noexcept` 做什么判断？判断依据是什么？

>move_if_noexcept 判断是移动对象还是拷贝对象。

>判断依据是：是否实现移动函数 以及 移动函数是否 noexcept。如果实现移动函数，且移动函数是 noexcept 的，就移动函数，否则拷贝对象。

>### Q9 copy-and-swap 为什么能同时解决「自赋值」「异常安全」「代码重复」三个问题？

>1.自己和自己交换没有问题  2.不太确定  3.多个地方可以复用

### Q10 `operator=` 参数按**值**传，为什么能一个函数同时当拷贝赋值和移动赋值？

在**拷贝构造/拷贝赋值**里写了 `std::move_if_noexcept(other.data_[i])`，

### 证据 7 · RAII 守卫的异常安全（搬运途中抛异常）

探针在第 3 次赋值时抛异常：

```
触发扩容前: size=4 cap=4
捕获异常: boom
异常后 size=4 cap=4          ← 三个成员一个没动，强异常保证成立
异常传播期间析构次数=8        ← temp 那块 8 格被 unique_ptr 自动释放，无泄漏
退出码 0                      ← 无堆损坏
```

### 证据 8 · Rule of 5 五条路径全通（最终版）

```
路径1 拷贝构造: b.size=3 | a.size=3      ← 源对象未被掏空
路径2 拷贝赋值: copy constructor ×1       ← 无多余拷贝
路径3 移动构造: d.size=2 | src.size=0     ← 源被掏空
路径4 移动赋值: move constructor ×1, src2.size=0
路径5 析构:     元素析构 4 次
自赋值:         a.size=3 未被毁
退出码 0
```

### 证据 9 · copy-and-swap 三版演进（分辨力来自打印序列）

```
版本一（swap 按值传参）—— 错：
  路径2: copy constructor ×2（多一次）
  路径4: copy constructor ×1, src2.size=3  ← 移动语义完全失效

版本二（operator= 按值传 + 函数体内又 temp(other)）—— 仍错：
  路径2: copy constructor ×2
  路径4: move constructor + copy constructor  ← 刚移进来的又拷一份

版本三（删掉 temp，直接 swap(other)）—— 正确：
  路径2: copy constructor ×1
  路径4: move constructor ×1, src2.size=0
```
